Deterministic Rule Engine — Manual Test UI

Direct testing surface for rule_engine/ via routes/compliance_routes.py. For the automatic, document-driven flow (LLM → rule engine, no manual entry), see the Live Pipeline Demo → instead. This manual page bypasses the LLM/RAG pipeline entirely — useful for testing individual rules in isolation with hand-picked numbers.

EMI Validation (EMI-001)

Recalculates EMI from principal/rate/tenure and compares it to the document's stated EMI, within tolerance.

Interest Rate Validation (INTEREST-001)

Compares the document's stated annual interest rate against the configured maximum (a placeholder default of 18% unless overridden via env vars — see rule_engine/config.py).

Mandatory Disclosure Validation (DISCLOSURE-001)

Checks that required disclosure fields are present and non-empty (placeholder required list: annual_percentage_rate, processing_fee, prepayment_penalty, grievance_redressal_contact — see rule_engine/config.py).
Tip: add all four placeholder fields with values to see PASS, or omit one / leave it blank to see FAIL.
